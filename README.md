# OpenLVI Bridge Core

**Open HVAC / OpenLVI Bridge — isolated module download**

Multi-vendor local Modbus, USB, BACnet and M-Bus bridge. Ouman USB protocol reader bundled.

**Validation:** experimental  
**Module:** openlvi-bridge  
**Source commit:** 6267d1b3924c5613b88ccf53fca905cfe8f4b580

## Install

Download this branch as a ZIP, extract it, and follow the module's
[full installation guide](https://github.com/artepe/Open-HVACBridge-homeassistant/blob/main/docs/OPENLVI_BRIDGE.md).
This is a source snapshot; do not install unrelated files or assume
that simulation testing proves physical device compatibility.

**Destination:** /config

## Safety

OpenLVI multi-vendor drivers are experimental; the included Ouman USB reader must not be configured twice on one port.

Contribute in [main](https://github.com/artepe/Open-HVACBridge-homeassistant/tree/main), not in a
download branch. The download branches are regenerated from main.
